## 내가 내린 판단

- 🥵 **기온**: 비교는 가진 데이터의 가장 옛 해(2000년)와 가장 최근 해(2023년)로 정하고, 밤 기온은 한 해가 아니라 2000년대와 최근 10년(2014~2023년)의 평균으로 비교했다.
- 🌏 **지진**: 지진은 USGS가 "South Korea"로 적은 2025년까지의 기록으로 정하고, 여진도 1건으로 셌으며, 지역은 가장 가까운 지명 50km 안만 묶고 흥해는 포항에 넣었다.
- 👨‍👩‍👧‍👦 **인구**: 인구는 OECD 지역 인구의 남녀 합으로 정하고, 전국으로 나누는 문항은 전국 값과 시·도 합이 같은 2020년으로 셌다.
- 🌀 **태풍**: 상륙은 경로 점이 남한 땅(제주 포함) 위에 찍힌 태풍으로 정하고, 대마도·규슈를 지난 태풍은 뺐으며, 가장 거센 태풍은 풍속으로 고르되 같으면 기압이 낮은 쪽으로 정했다.
- 🏯 **세계유산**: 세계유산은 나라가 대한민국 하나인 유네스코 세계유산으로 정하고, 여러 장소를 묶은 유산도 1건으로 셌으며, 북한 유산과 무형·기록유산(예: 직지심체요절)은 뺐다.
- 🍶 **술**: 소주 1병은 16.5% · 360mL로 정하고, 한 달 값은 1년 값을 12로 나눴으며, 2001년과 값이 똑같은 2000년과 남녀를 나눈 문항은 뺐다.
- ⚡ **전기**: 기준 해는 잠정값인 2025년을 빼고 2024년으로 정하고, 하루 값은 1년 값을 365로 나눴으며, 재생에너지는 수력·태양광·풍력·바이오를 합친 값으로 셌다.
- ❄️ **눈**: 눈 온 날은 하루 0.1cm 이상으로 정하고, 첫눈은 뉴스처럼 쌓이지 않아도 처음 내린 날로 셌으며, 지점은 시·도청 소재지 17곳에 대관령·울릉도·강릉·속초를 더했다.

## 데이터가 오는 길

```
   [내 노트북]                                   [인터넷]

   tools/fetch_all.py      공개 데이터 6곳에서 받기 (키·로그인 없음)
        ↓  data/raw/  약 19MB   ← git 에도 배포에도 올라가지 않습니다
   tools/build_topics.py   원본에서 문항 계산
        ↓
   topics/*.json  약 40KB  ← 이것만 올라갑니다
```

원본을 브라우저로 보내서 거기서 평균을 내는 게 아닙니다. **평균은 내 노트북에서 미리
내고, 그 결과만 싣습니다.** 그래서 폰에서 즉시 뜹니다.
